# HF Studio — site publicado

Site no ar: https://theufirminoo.github.io/site-hfstudio/

Esta é a versão **gerada** (pronta para o navegador). O código-fonte fica em
`theufirminoo/desktop-tutorial`, pasta `hf-studio/`. Não edite estes arquivos
à mão: altere o código-fonte, rode
`PATH_PREFIX=/site-hfstudio/ npm run build` e copie o conteúdo de `dist/` para cá.
